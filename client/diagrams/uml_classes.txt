SINGLETON PATTERN (used by all services)
------------------------------------------
constructor() {
  if (ClassName._instance) return ClassName._instance;  // return existing
  // ... initialize ...
  ClassName._instance = this;                           // save instance
}
export default new ClassName();                         // export single instance


DATA FLOW
----------
User Action
    |
    v
React Component
    |-- calls --> MockApiService (async, returns Promise)
    |-- calls --> Logger.info/warn/error
    |-- calls --> Notify.success/error
    |
    v
MockApiService
    |-- reads/writes --> StorageService (localStorage)
    |-- reads --> ConfigService (apiDelay)
    |-- calls --> Logger (debug info)
    |
    v
UI Update (setState in component)
