USE CASE DESCRIPTIONS
======================

UC5 - Create Exam
  Pre-condition:  Logged in as teacher
  Main Flow:      Fill title, description, duration, passing score
                  Add questions (min 1), fill 4 options per question
                  Select correct answer per question
                  Click "Create Exam (Draft)"
  Post-condition: New exam created with status=Draft
  Exception:      Validation fails if title empty or options incomplete

UC8 - Publish Exam
  Pre-condition:  Exam exists with status=Draft
  Main Flow:      Click Publish on exam card
  Post-condition: status=Published, visible to all students
  Note:           Irreversible path to Published (can still Close after)

UC13 - Take Exam
  Pre-condition:  Logged in as student, exam status=Published, not yet attempted
  Main Flow:      Click "Take Exam", answer questions, click Submit
  Alternate Flow: Timer reaches 0 -> auto-submit with unanswered = wrong
  Post-condition: Attempt saved with auto-calculated score
                  Student sees answer review (correct/wrong per question)
  Exception:      Cannot take same exam twice (hasAttempted check)

UC11 - View Student Results
  Pre-condition:  Logged in as teacher
  Main Flow:      Click Results on any exam, select exam from dropdown
  Post-condition: Table shows all attempts with names, scores, timestamps
                  Summary: submissions count, avg score, pass rate %
