RELATIONSHIPS
-------------
USER (teacher) --[creates]--> EXAM  (1 teacher : many exams)
USER (student) --[submits]--> EXAM_ATTEMPT  (1 student : many attempts)
EXAM           --[has]------> QUESTIONS  (1 exam : many questions, embedded)
EXAM           --[has]------> EXAM_ATTEMPT  (1 exam : many attempts)


EXAM STATUS FLOW
----------------
  [Draft] --publish--> [Published] --close--> [Closed]
     ^                                            |
     |                                            |
     +-------------- reopen ---------------------+

  Draft:     visible only to creator teacher, editable, deletable
  Published: visible to all students, can be taken, not deletable
  Closed:    no new submissions accepted, results still visible


STORAGE KEYS (localStorage with prefix 'etest_')
-------------------------------------------------
  etest_db_users     -> User[]
  etest_db_exams     -> Exam[]
  etest_db_attempts  -> ExamAttempt[]
